# 📌 Project

## Name

Kasper Template Two

## Version

v0.1.0

## Problem

Most beginners can recreate a design but struggle to write scalable and maintainable front-end code.

## Target Users

- Myself.
- Recruiters reviewing my code.
- Developers interested in clean front-end architecture.

## Core Value

Learn how to build production-quality front-end projects rather than simply reproducing a design.

## Definition of Done

- [ ] Sections implemented.
- [ ] Responsive on all target screen sizes.
- [ ] accessible web page
- [ ] Semantic HTML.
- [ ] Clean BEM naming.
- [ ] CSS organized.
- [ ] Manual testing completed.
- [ ] Reusable CSS.
- [ ] Easy to maintain.

---

# ⚙ Requirements

## Functional Requirements

- Responsive navigation.
- Interactive menu.
- Responsive layout.
- Working contact section.

## Non-Functional Requirements

- Mobile First.
- Semantic HTML.
- BEM methodology.
- Organized CSS.
- Reusable components.
- Cross-browser compatibility.

## Constraints

- HTML + CSS + Vanilla JavaScript only.
- No CSS frameworks.
- No UI libraries.
- Follow BEM naming conventions.

---

# 👤 User Flow

1. Open the landing page.
2. Explore the available sections.
3. Navigate smoothly through the website.
4. View correctly on any screen size.

# 🏗 Architecture
